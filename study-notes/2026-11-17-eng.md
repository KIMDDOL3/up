# 오늘의 미션 (화요일 듣기 — 못 들었을 때 자연스럽게 되묻는 표현)

- 오늘의 포인트: **원어민과 대화하다 못 들었을 때 "What? Again?"처럼 튀어나오면 어색하다. 실제로는 "Sorry, I didn't quite catch that" 같은 되묻기 덩어리가 정해져 있다.** 미드에서 회사원들이 "Sorry, you broke up for a second"(잠깐 끊겼어요)라고 하면 화상통화 장면이고, "Come again?"은 친구 사이의 가벼운 되묻기다. 듣기 훈련의 핵심도 이것과 연결된다 — 3-listening.md는 듣기를 "모든 단어를 잡는 일"이 아니라 "한 단어를 놓쳐도 맥락·관계·확인으로 이해를 다시 잇는 일"로 본다. 게다가 원어민은 did you를 "d'ju", want to를 "wanna"로 뭉개서 말하기 때문에(연음·약화), 알던 단어도 소리로는 못 알아듣는 경우가 많다. 그래서 못 들었을 때 쓰는 되묻기 표현을 덩어리째로 외워두면, 대화가 끊기지 않고 바로 복구된다.
  - 인용: 3-listening.md "听力进步有时不是'听见更多词'，而是漏掉一个词以后仍然知道怎样继续。" (듣기의 진보는 때때로 '더 많은 단어를 듣는 것'이 아니라, 한 단어를 놓쳐도 어떻게 계속해야 하는지 아는 것이다.)
  - 왜 이런 규칙인가: 원어민은 "못 들었다 = 대화 실패"가 아니라 "복구 이벤트 하나"로 취급한다. 그래서 되묻기 표현에는 Sorry/Just 같은 완충어가 거의 항상 붙고, 뒤에는 구체적 요청(could you say that again / repeat the last part)이 온다. 뜻만 외운 학습자는 뻣뻣한 "Please repeat"를 쓰거나 아예 웃으며 넘어가 버리는데, 실제 회의에서는 못 들은 숫자·마감일을 그대로 두는 게 제일 위험하다. 되묻기 덩어리를 소리째 저장해두면 못 들었을 순간에 생각 없이 나온다.
  - 흔한 실수: 틀린 문장 — "Please repeat again? I don't listen you." → 고친 문장 — "Sorry, I didn't quite catch that — could you say it again?" (repeat again은 이중 표현, listen you는 hear의 오용. 되묻기는 Sorry 완충 + catch + could you 조합이 자연스럽다.)

- 오늘의 표현 5개 (실제 대화에서 바로 쓰는 문장):
  1. "Sorry, I **didn't quite catch that** — could you say the server name again?" — 미안, 잘 안 들렸어. 서버 이름 다시 말해줄래? (개발·회의)
  2. "You **cut out** for a second — can you repeat the last number?" — 잠깐 목소리가 끊겼어. 마지막 숫자 다시 말해줄래? (개발·화상회의)
  3. "Just to make sure — **are you saying** the launch is next Tuesday, not this one?" — 확실히 하자면, 출시일이 다음 주 화요일이라는 거지, 이번 주가 아니라? (직장·확인)
  4. "**Come again?** I didn't get the meeting time." — 뭐라고? 회의 시간을 못 들었어. (일상·친한 사이)
  5. "Sorry, this café is so loud — **what did you say** the Wi-Fi password was?" — 미안, 카페가 너무 시끄러워서 와이파이 비번이 뭐라고 했지? (일상·카페)

- 미션 (15~20분): **30초~2분 영상 클립으로 5단계 사다리 타기 + 되묻기 표현 3개 소리 내어 말하기**
  - 절차:
    1. **재료 고르기(4분)**: 좋아하는 영어 유튜브/팟캐스트에서 30초~2분 클립 하나를 고른다. 자막은 끈 상태로 두되 첫 재생 때는 화면을 보지 않는다(챕터의 '무자막 첫 듣기' 규칙).
    2. **수행(10분)**: ① 첫 재생 후 한 줄 주제 + 확실한 디테일 1개를 적는다. ② 안 들린 구간만 5~20초로 반복 재생하며 "단어를 몰라서인가, 연음에 뭉개져서인가"를 판정한다. ③ 자막으로 그 구간만 확인한 뒤 자막을 끄고 다시 재생 — 소리만으로 뜻이 떠오르는지 확인. ④ 마지막으로 오늘의 되묻기 표현 3개(didn't quite catch that / cut out / are you saying~)를 각각 3회씩 소리 내어 말하고 녹음한다.
    3. **확인(5분)**: 녹음을 들으며 체크 — (a) Sorry 같은 완충어가 빠졌는가, (b) "catch that"이 한 호흡으로 나오는가. 클립에서 못 들었던 구간을 오늘 표현으로 되묻는 문장 1개를 만들어 마무리 녹음.
  - 소요: 15~20분
  - 완료 조건: 이 노트 `## 기록`에 못 들었던 구간 + 되묻는 문장 1개 기록

## 미니 퀴즈 (11-17 듣기)

1. 회의에서 마지막 숫자를 못 들었을 때 가장 자연스러운 것은?
   (a) Sorry, I didn't quite catch that — could you repeat the last number? (b) Please repeat again? I don't listen you.
2. 화상통화에서 상대 목소리가 잠깐 끊겼을 때 쓰는 표현은?
   (a) You cut out for a second — can you say that again? (b) You stopped being heard for a second.
3. 빈칸: "___ to make sure — are you saying the deadline is Friday, not Thursday?" (힌트: 확인할 때 붙이는 완충 덩어리 3단어)

## 퀴즈 정답 (11/18 공개용)

1. (a) — catch가 '소리를 잡다'라는 뜻으로 되묻기의 표준 동사. listen은 '들으려다'이지 '들렸다'가 아니므로 (b)는 어색.
2. (a) — cut out은 신호·목소리가 끊기는 것을 나타내는 구어 표준. (b)는 직역이라 원어민이 쓰지 않는다.
3. Just to make sure — 확인 요청 앞에 붙는 완충 덩어리. 뒤에 are you saying~을 이어 붙이면 상대의 말을 복기하며 확인하는 자연스러운 흐름이 된다.
