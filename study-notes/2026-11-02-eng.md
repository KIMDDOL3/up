# 오늘의 미션 (월요일 word-list — prompt 한 단어를 세 가지 쓰임으로)

- 오늘의 표현: **prompt** — JavaScript.md 등재 단어이지만 사전 첫 줄 뜻만 외우면 놓치는 다의어. ①명사: (AI에게 주는) 지시문, (화면의) 입력 안내 ②동사: ~하도록 유도하다/재촉하다 ③형용사: 신속한, 즉각적인. 파생: promptly(부사), promptness(신속함).
- 미션: **prompt의 3가지 품사를 상황별로 소리 내어 말하기**
  - 절차:
    1. **재료 고르기(2분)**: 아래 예문 5개를 읽고 명사·동사·형용사 쓰임이 각각 어느 문장인지 표시하기.
    2. **변형·발화(10분)**: ① AI 도구에 쓸 나만의 지시문(prompt) 1문장 ② 화면이 묻는 상황을 내 상황으로 바꿔 1문장 ③ 회사 이메일 끝에 신속한 회신 감사 표현 1문장 ④ 어떤 일이 나를 행동하게 만든 경험 1문장. 각각 소리 내어 말하고 녹음해 확인하기.
    3. **확인(3분)**: 사전에서 prompt 발음 확인(프롬프트의 '프'는 p+r 연음). "prompt reply"로 실제 이메일 문구 검색해 원어민 쓰임 2개 찾기.
    4. **연결(3분)**: 오늘 쓰는 AI 도구에 실제로 영어 prompt 1개를 입력해 답을 받아보기 — 학습한 단어를 진짜 작업에 호출.
- 소요: 15~20분
- 완료 조건: 이 노트 `## 기록`에 ①녹음한 문장 수 ②고친 발음/쓰임 1개 ③실제 입력한 영어 prompt 1줄 기록
- 커밋 메시지: `eng: 2026-11-02 done`

> 핵심 근거: 2-vocabulary.md "多义词最容易制造'明明认识却读错'的错觉" (다의어는 '분명 아는데 잘못 읽는' 착각을 가장 쉽게 만든다), "不要把词典第一页的中文释义机械搬进每个场景" (사전 첫 페이지의 첫 번째 뜻을 모든 상황에 기계적으로 가져오지 마라).

## 퀴즈 정답 (11/3 공개용)

1. (a) — prompt가 형용사로 쓰여 "신속한". promptly(부사)는 "Please reply promptly."처럼 동사를 수식.
2. (a) — prompt + 사람 + to do: "~하도록 유도하다/묻는다". 화면·시스템이 주어가 되는 정격 표현.
3. prompt — AI에게 주는 지시문이라는 명사 쓰임. JavaScript 문서의 prompt와 같은 철자, 다른 맥락.
