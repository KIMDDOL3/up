# 오늘의 미션 (화요일 듣기 — 연음·축약을 실제 대화에서 잡기)

- 오늘의 표현: **연음·축약(connected speech)** — 원어민은 going to를 gonna, want to를 wanna, got to를 gotta, did you를 "디쥬"로 줄여 말한다. 글로 아는 표현이 소리에서는 다른 단어처럼 들리는 이유가 바로 이것.
- 미션: **짧은 실제 클립 1개로 축약 듣기 루프 돌리기**
  - 절차:
    1. **재료 고르기(3분)**: 드라마·팟캐스트·유튜브에서 30초~2분 대화 클립 1개 고르기. 자막 없이 1회 재생(정속, 일시정지 금지)하고 "한 줄 주제 + 못 들은 구간"만 메모.
    2. **수행(10분)**: 못 들은 구간만 5~20초로 반복 재생 → 영어 자막/스크립트 열어 원래 문장 확인 → gonna/wanna/gotta/did you처럼 축약된 표현 3개 찾아 소리 내어 따라 말하기.
    3. **확인(5분)**: 자막을 끄고 같은 구간 다시 듣기. 소리만으로 뜻이 떠오르면 성공. 오늘 예문 5개 중 2개를 자기 상황으로 바꿔 소리 내어 말하기(녹음 추천).
  - 소요: 15~20분
  - 완료 조건: 이 노트 `## 기록`에 ①클립 제목 ②찾은 축약 3개 ③자막 끄고 들었을 때 잡힌 구간 1개 기록
- 커밋 메시지: `eng: 2026-11-03 done`

> 핵심 근거: 3-listening.md "已知但没听出：字幕一看就懂，声音中却无法切分" (이미 아는 표현인데 소리에서는 끊어지지 않아 못 듣는 경우 — 자막을 보면 다 이해되는데 소리만 흐르면 잘라내지 못한다). "字幕是一架可以撤走的梯子" (자막은 언제든 치워 둘 수 있는 사다리일 뿐, 부채도 의존도 아니다).

## 미니 퀴즈 (11-03)

1. 회의가 길어져 일단 자리를 떠야 할 때, 가장 자연스러운 말은?
   (a) I gotta run — talk later? (b) I got run — talk later? (c) I got to running — talk later?
2. 동료에게 커피 마시러 가자고 할 때, 원어민이 실제로 말하는 축약형으로 가장 알맞은 것은?
   (a) Do you want to grab a coffee? → "Wanna grab a coffee?" (b) Are you wanting coffee grabbing? (c) Do you like coffee to grab?
3. 빈칸: "___ you finish the report?"라고 들렸는데, 스크립트를 보니 "Did you finish the report?"였다. did you가 소리에서는 보통 어떻게 들리는가? ( /___/ )

## 퀴즈 정답 (11/4 공개용)

1. (a) — got to가 축약된 gotta. "gotta run"은 "가야 해"라는 가장 흔한 일상 표현.
2. (a) — want to가 wanna로 축약. (b) (c)는 실제로 쓰이지 않는 비문.
3. /dɪdʒə/ — "디쥬". did의 d+you의 y가 만나 ㅈ 소리로 합쳐진다(음성 융합).
