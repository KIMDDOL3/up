# 오늘의 미션 (문법)

- 미션: **시제·상(time & aspect) 삼중 대비 훈련** — `docs/threads/part-1/grammar.md` §「時間與體」의 세 문장 패턴을 그대로 활용해, 아래 시제 3개(일반 과정 / 진행 중 결과 / 현재 완료) 각각으로 **내 실제 상황 기반 문장 3개씩 = 총 9개** 작성하기. 작성 후 각 문장 아래에 "이 시제가 어떤 의미 차이를 만드는지" 한국어로 한 줄 메모.
  - 예시 패턴:
    - `We fixed the issue yesterday.` (단순 과거 — 끝난 사건)
    - `We were fixing the issue when the service restarted.` (과거 진행 — 다른 일이 일어난 시점의 배경)
    - `We have fixed the issue, so deployment can continue.` (현재 완료 — 현재 결과가 남아 있음)
- 소요: 15~20분
- 완료 조건: 9개 문장 + 각 의미 차이 메모가 이 노트 아래 기록됨
- 커밋 메시지: `eng: 2026-10-15 done`

> 참고 (CC BY-NC 4.0, docs/threads/part-1/grammar.md): "每次先画事实时间线，再决定形式。" — 각 문장을 쓰기 전에 실제 시간선을 먼저 그려라. 시간선이 설명되지 않으면 시제 선택도 흔들린다.
