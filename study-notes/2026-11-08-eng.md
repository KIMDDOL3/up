# 오늘의 미션 (일요일 word-list — Java 단어장에서 '일상 쓰임' 단어 5개)

- 오늘의 포인트: **Java 단어장의 단어들은 기술 의미로만 외우면 손해다 — 그중 절반은 일상 대화에서 더 자주 쓰이는 평범한 영어 단어다.** 오늘은 default, retrieve, inconsistent, obsolete, costly 다섯 개를 뽑았다. default는 '기본값'이지만 일상에선 "by default(기본적으로)"로 말하는 습관 표현이고, retrieve는 '검색해서 가져오다'지만 사무실에선 그냥 '꺼내 오다'다. inconsistent는 코드 일관성 논쟁용 같지만 실제로는 "규정이 일관성 없다"는 직장 불평에서 제일 흔하다. obsolete는 기술 폐기 전문 용어처럼 보이지만 "내 폰이 낡아서 앱이 안 깔려"까지 커버하는 일상 형용사고, costly도 '비싼'이 아니라 '나중에 값비싼 대가를 치르는' 뉘앙스로 회의와 일상 양쪽에서 다 부린다. 단어장을 볼 때 기술 뜻 하나만 외우지 말고, 그 단어가 평범한 문장에서 어떤 자리에 앉는지를 함께 확인하는 게 이 일요일 라인의 핵심이다.
  - 인용: 2-vocabulary.md "词汇量不是仓库盘点。词汇能力是：在真实输入里认出一个表达，在上下文中判断它此刻的意思，在需要时迅速调用，并让另一个人据此理解、回应或继续工作。" (단어량은 창고 재고 목록이 아니다. 단어 능력이란 실제 입력에서 표현을 알아보고, 문맥에서 지금 이 순간의 의미를 판단하고, 필요할 때 빠르게 꺼내 써서 상대가 이해하고 응답하거나 일을 이어가게 만드는 것이다.)
  - 왜 이런 규칙인가: 기술 단어장은 '그 문서에서 쓰인 뜻'만 싣는다. 그런데 default, retrieve 같은 단어는 원래 영어권 사람이 카페·회의·가정에서 매일 쓰는 말이라, 기술 뜻만 외우면 정작 일상 문장에서 눈앞에 있어도 못 꺼낸다. 반대로 일상 뜻을 먼저 잡으면 기술 문서 의미는 훨씬 쉽게 붙는다 — 특수 의미는 항상 일반 의미의 확장이기 때문이다. 흔한 실수: "The old printer is obsolete."를 오해해서 "프린터가 객체지향적이다?"라고 읽는 식으로, 단어장 순서(기술 뜻 먼저)를 그대로 문장에 적용하는 것.

- 오늘의 표현 5개 (일상·직장에서 실제로 말하는 문장):
  1. "The report is set to PDF **by default**, so just hit export." — 보고서는 기본 설정이 PDF라서, 그냥 내보내기만 누르면 돼. (직장·회의)
  2. "Give me a sec — I'll **retrieve** the file from the shared drive." — 잠깐만요, 공유 드라이브에서 파일 꺼내 올게요. (직장·전화)
  3. "The approval process is **inconsistent** — one team says yes same day, another takes a week." — 승인 절차가 일관성이 없어. 어떤 팀은 당일 승인하는데 어떤 팀은 일주일 걸려. (직장·불평 토로)
  4. "My old phone is basically **obsolete** — new apps won't even install." — 내 옛날 폰은 사실상 낡은 거라 새 앱이 아예 안 깔려. (일상·가족 대화)
  5. "Skipping the checkup now might turn out **costly** later." — 지금 검진을 건너뛰면 나중에 더 큰 대가를 치를 수도 있어. (일상·건강 상담)

- 미션 (15~20분): **다섯 단어로 '내 실제 상황 문장' 만들어 소리 내어 말하기 + 녹음**
  - 절차:
    1. **재료 고르기(5분)**: 위 예문 5개를 훑고 각 단어마다 '내가 실제로 겪은 상황' 하나씩 메모 — 예: 회사 기본 툴 설정, 공유 폴더에서 꺼낸 자료, 회사 규정 모순, 집의 낡은 기기, 미뤄둔 점검.
    2. **수행(10분)**: 각 상황을 한 문장 영어로 만든 뒤 소리 내어 3회씩 말하고 휴대폰에 녹음. 원형 예문을 그대로 읽지 말고 주어·시제를 내 상황에 맞게 바꿀 것 (예: "Our meeting room is booked by default on Mondays.").
    3. **확인(5분)**: 녹음을 다시 들으면서 체크 — 다섯 단어가 모두 나왔는가, by default처럼 '한 덩어리' 표현이 자연스럽게 이어지는가. 뜸들이는 단어 하나만 골라 문장째 3회 반복.
  - 소요: 15~20분

## 미니 퀴즈 (11-08)

1. 다음 중 'default'가 '기본 설정'으로 쓰인 문장은?
   (a) The app opens in dark mode by default. (b) He defaulted on his loan last year.
2. '낡아서 더 이상 쓸모없는'을 나타내는 단어는?
   (a) obsolete (b) appropriate
3. 빈칸: 공유 드라이브에서 파일을 꺼내 올 때 — "Give me a sec, I'll ___ the file from the shared drive." (한 단어 동사)

## 퀴즈 정답 (11/9 공개용)

1. (a) — "by default"는 '특별히 바꾸지 않으면 기본으로'라는 설정·습관 표현. (b)의 default는 '빚을 갚지 못하다(부도내다)'로 완전히 다른 의미.
2. (a) — obsolete는 '구식이 되어 더 이상 쓸모없는'. (b) appropriate는 '적절한'으로 뜻이 정반대 방향.
3. retrieve — 파일·데이터·물건을 '찾아서 꺼내 오다'의 표준 동사. 검색창 문구 "No results retrieved"도 같은 단어.
